## 제작 프롬프트 요약

공통: ads-marketing. COFFEE & SPOON 카페 키오스크용 5:4 실사 광고. 작은 화면에서도 읽히는 큰 한국어 제목과 짧은 참여 안내. 귀여운 캐릭터와 이모지 제외. 크림·에스프레소·앰버 색상, 안전 여백 확보.

사진: 크림 배경, 카페에서 웃는 성인 친구들의 포토 스트립과 아이스커피 실사. 제목 ‘오늘의 순간을 사진으로 남기세요’. 안내 ‘메뉴에서 사진 찍기 선택 / 결제 후 바로 촬영’. PHOTO EVENT, 서비스 준비 중.

스마일: 에스프레소 배경, 카페에서 자연스럽게 웃는 성인 여성 실사와 얼굴 인식 프레임. 제목 ‘활짝 웃으면, 기분 좋은 할인’. 안내 ‘결제 전 카메라를 보고 / 활짝 웃어 주세요’. SMILE EVENT, 스마일 할인 · 서비스 준비 중. 임의 할인율 금지.
