# 얼굴 인증 세부 흐름 (10/29 교체)

10/28 회의에서 다른 사람 얼굴로 로그인이 뚫렸다. 그래서 직접 짠 비교(SFace)와 고개 동작 대신
공개 모델을 쓰고, '얼굴 인증' 한 칸을 아래처럼 나눴다. 코드는 `face/opencv_face.py`, `face/quality.py`, `face/engines.py`.

```
회원 ID 입력
  ├─ 얼굴 미등록 ─────────────→ 비밀번호 로그인 안내
  ├─ 얼굴 로그인 잠김(3번 실패) → 비밀번호 로그인 (성공하면 잠금 풀림)
  └─ 얼굴 등록 방식이 예전(SFace) → 비밀번호 확인 후 얼굴 다시 등록
  ▼
F1 카메라 열기 ── 실패 → "카메라 문제" + 비밀번호
  ▼
F2 얼굴 찾기 (YuNet) ── 앞 약 50cm 안의 얼굴만 센다 (뒤에 선 사람은 무시)
     D435: 코까지 거리 0.55m 이하 / 웹캠: 얼굴 폭 120px 이상
     0명: "카메라 앞에 서 주세요" (등록은 "타원 안으로") / 멀리만 있음: "50cm 안으로" / 2명 이상: "한 사람만"
  ▼
F3 가림 확인 ── 두 눈 주변 피부색 없음+어두움: "선글라스·모자 벗기"
             └─ 입 주변 피부색 없음: "마스크 벗기"   (약 3초 계속되면 멈추고 안내)
  ▼
F4 품질 확인 ── 너무 작음 "가까이" / 고개 돌림(약 18도 넘게) "정면" / 어두움 "밝은 곳" / 흔들림 "멈추기"
  ▼
F5 진짜 사람 ── MiniFASNet 2개 평균 '진짜' 확률 0.6 이상이 최근 10장 중 7장
             (D435가 있으면 깊이로 코 돌출도 함께)  약 2초 계속 '사진'이면 → 사진 거절(실패 1회)
  ▼
F6 비교 (ArcFace 512개 숫자, 코사인 유사도)
     ① '진짜'로 나온 5장 중 4장 이상, 그리고 평균이 기준(0.45) 이상
     ② 다른 등록 얼굴과 더 닮았으면 거절 (팀원끼리 헷갈림 방지)
  ├─ 통과 → 03 My Menu, 실패 횟수 0으로
  └─ 실패 → 실패 +1, 남은 횟수 안내 · 3번이면 얼굴 로그인 잠금
```

**모자 정책 (10/29 결정):** 눈·코·입이 보이면 모자를 써도 통과시킨다(Face ID와 같음). 모자는 남의 계정을 뚫는 데
도움이 되지 않고, 이마 검사로 막으면 앞머리 있는 사람까지 막히기 때문이다. 모자챙이 눈을 가리면 F3에서 걸린다.

**화면 (10/29 아침 수정):** 카메라 영상은 등록·로그인 모두 보여 주지 않고 얼굴 기호(Face ID 모양)만 그린다.
타원에 맞출 필요 없이 50cm 안에 서면 된다. 02 로그인은 창 전체를 덮지 않고 왼쪽 키보드 자리에 얼굴 기호,
오른쪽 칸에 지금 할 일 한 줄('카메라 앞에 서 주세요' · '정면을 보고 잠시 멈춰 주세요' · '확인하고 있어요…')을 띄운다.

등록(10-B)도 F1~F5가 같고, 10장을 모은 뒤 10장이 서로 충분히 닮았는지(0.6 이상) 확인하고 평균을 저장한다.

## 숫자 (현장에서 바꿀 수 있는 것)

| 값 | 기본 | 위치 |
|---|---|---|
| 얼굴 유사도 기준 | 0.45 | 환경변수 `KIOSK_FACE_THRESHOLD` |
| 진짜 얼굴 확률 | 0.6 | `face/engines.py REAL_THRESHOLD` |
| 실패 잠금 | 3번 | `domain/customers.py MAX_FACE_FAILURES` |

공개 사진 시험: 같은 사람 0.92~0.99, 다른 사람 0.03~0.07. 웹캠에서 본인 점수는 실제로 재 봐야 한다
(성공하면 터미널에 `[얼굴 로그인] ID · 얼굴 유사도 …`가 찍힌다).

## 한계 (보고서에 그대로 적는다)

- 가림 판정은 눈·입 주변의 밝기·피부색을 보는 근사 판정이다. 살색 마스크나 아주 어두운 조명에서는 틀릴 수 있다.
- MiniFASNet은 카메라·조명에 따라 정확도가 달라진다. 고화질 영상·정교한 3D 마스크까지 막는 상용 수준은 아니다.
- ArcFace(buffalo_l) 모델은 비상업 연구용 라이선스다. 상업용으로 쓰려면 별도 허가가 필요하다.
- 사진·영상은 저장하지 않는다. 512개 숫자만 암호화 금고(`face_profiles`)에 저장한다.
