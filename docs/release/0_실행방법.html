☕ 키오스크 실행 방법

0

압축 풀기

  1. 받은 ZIP 파일에 마우스 오른쪽 → 모두 압축 풀기
  2. 압축을 푼 폴더를 엽니다. 압축을 안 풀고 실행하면 안 돼요.
1

Python 설치 (처음 한 번만)

  1. python.org/downloads 에서 노란 Download Python 버튼
  2. 받은 파일 실행 → 첫 화면 아래의 ✓ Add python.exe to PATH 꼭 체크
  3. Install Now → 끝나면 Close
이미 Python이 있으면 건너뛰어도 돼요.
2

1_처음설치 더블클릭 (처음 한 번만)

  1. 검은 창이 뜨면 아무 키나 누르기 Enter
  2. 5~10분 기다리기 (인터넷 필요)
  3. “지금 인터넷에서 받을까요? 약 300MB” → N
  4. “준비 끝!” 이 나오면 아무 키나 눌러 창 닫기
파란 창 “Windows의 PC 보호”가 뜨면 → 추가 정보 → 실행
