1. 준비물

  • Windows 10 또는 11 컴퓨터 (화면 1200×800 이상 권장)
  • Python 3 — 없으면 python.org에서 설치합니다. 설치 첫 화면에서 “Add python.exe to PATH”를 꼭 체크하세요.
  • 처음 설치할 때만 인터넷 (프로그램 묶음 수백 MB를 받습니다)
  • 실제 모드에서 얼굴 로그인을 쓰려면 카메라 (시연 모드는 카메라가 없어도 됩니다)
폴더 안에서 쓰는 파일은 세 개뿐입니다: 1_처음설치 → 2_시연모드_실행 → (필요하면) 3_실제모드_실행. 모두 더블클릭으로 실행합니다.

2. 처음 설치 — 1_처음설치.bat

  1. 폴더에서 1_처음설치를 더블클릭합니다. 검은 창이 열리고 설치 상태를 확인합니다.
  2. “아무 키나 누르면 설치를 시작합니다”가 나오면 아무 키나 누릅니다. 몇 분 걸립니다.
  3. “얼굴 인증 모델을 받을까요?”는 시연만 할 거면 N, 실제 카메라 로그인까지 쓸 거면 Y를 누릅니다(약 300MB).
  4. “준비 끝!”이 보이면 창을 닫습니다. 한 번만 하면 됩니다.
설치를 깜빡하고 2번을 먼저 눌러도 괜찮습니다. 2번이 알아서 설치부터 합니다.

시연 모드는 연습용 샘플 데이터로 켜집니다. 무엇을 눌러도 컴퓨터에 저장되지 않고, 끄면 처음 상태로 돌아갑니다.

  • 60초 동안 아무것도 안 누르면 45초에 경고가 뜨고, 60초에 대기 화면으로 돌아갑니다. 넣은 현금이 있으면 자동으로 돌려줍니다.

4. 비회원으로 주문해 보기

  1. 시작 화면에서 비회원 주문을 누릅니다.
  2. 왼쪽 줄에서 커피·논커피·디저트 같은 분류를 고르고, 메뉴 카드를 누릅니다.
  3. 옵션 창에서 온도(HOT/ICE), 사이즈, 추가, 수량을 고르고 장바구니 담기를 누릅니다. 딸기라떼처럼 ICE만 되는 음료는 ICE만 보입니다.
  4. 오른쪽 장바구니 확인 → 결제하기를 누릅니다.
  5. 현금 화면에서 지폐·동전 버튼을 눌러 돈을 넣습니다(시연용). 충분하면 결제 완료가 켜집니다.
  6. 완료 화면에 대기 번호와 거스름돈이 나옵니다. “더 주문하시겠어요?”에서 아니요를 누르거나 15초가 지나면 끝납니다.
돈을 잘못 넣었으면 투입 취소 · 반환을 누르면 넣은 돈을 모두 돌려줍니다. 남은 금액에 천 원 아래 잔돈이 있으면 “동전 줄이기 팁”이 나옵니다 — 그 금액을 동전으로 같이 넣으면 거스름돈에 동전이 없어요.

5. 회원으로 주문해 보기

  1. 시작 화면에서 회원 주문 → 화면 키보드로 아이디 bomin을 입력합니다.
  2. 시연 모드에서는 카메라가 없으니 비밀번호로 로그인을 누르고 1234를 입력합니다. (실제 모드에서는 얼굴 인증을 누르고 카메라를 정면으로 보면 됩니다.)
  3. 회원은 My Menu가 첫 화면입니다. 메뉴를 담은 뒤 결제로 가면 쿠폰·포인트 화면이 한 번 더 나옵니다.
  4. 현금 결제 때 거스름돈을 포인트로 적립할 수도 있습니다(회원만).
  5. 장바구니에서 개인 컵(텀블러)으로 받기를 체크하면 음료 1잔마다 에코 포인트를 더 받습니다(회원만).
  6. 자주 시키던 메뉴는 옵션 창을 열면 평소 고르던 옵션(ICE·L·샷 추가 등)이 미리 골라져 있습니다.
알레르기 경고: bomin은 우유 알레르기로 등록되어 있어서 카페라떼를 담으면 “알레르기 주의”가 뜹니다. 그래도 담기를 누르면 담깁니다.
  • 아이디·비밀번호를 잊었으면 로그인 화면의 아이디·비밀번호를 잊었어요로 갑니다. 아이디는 전화번호로 찾고, 비밀번호는 본인 확인 뒤 임시 비밀번호(6글자)를 받아 로그인하면 바로 새 비밀번호를 정합니다.
  • 얼굴 인증이 3번 연속 실패하면 얼굴 로그인이 잠깁니다. 비밀번호로 로그인하면 다시 풀립니다.
  • 회원 카드(RFID): 로그인 화면 비밀번호로 로그인 → 비밀번호 확인 후 회원 카드 연결로 카드를 연결해 두면, 다음부터 카드를 찍는 것만으로 로그인을 시작합니다(리더기가 있을 때).

6. My Menu · 인기 · 카페인 알리미

최근 주문 다시 담기

지난번 주문을 통째로 장바구니에 다시 담습니다. 다시 담기 ▶ 한 번이면 됩니다.

좋아요(♥)

메뉴 옵션 창 오른쪽 위 ♡ 좋아요를 누르면 My Menu에 모입니다.

인기 탭

왼쪽 줄의 인기에서 좋아요순 · 판매순 · 계절 인기순으로 순위를 볼 수 있습니다(비회원도 볼 수 있음).

카페인 리포트와 알리미

  • 그래프 위 이번 주 · 주별 · 월별을 누르거나 그래프를 직접 누르면 보기가 바뀝니다.
  • 오른쪽 위 톱니바퀴를 누르면 카페인 알리미 설정 창이 열립니다. ‘잔’ 또는 ‘mg’를 고르고 −/+로 이번 주 제한을 정합니다.
  • 제한을 넘게 담으려 하면 “그래도 담을까요?”를 묻습니다. 예는 담기, 아니요는 담지 않고 닫기입니다.

7. 승차권 사기 (시뮬레이션)

왼쪽 줄 승차권 탭에서 예매표 출력 또는 승차권 구매를 할 수 있습니다. 실제 버스 회사와 연결되지 않은 연습용입니다.

  1. 승차권 구매 → 도착지(예: 대전복합)와 날짜를 고르고 조회.
  2. 시간표에서 버스를 고르고 인원·좌석을 고릅니다. 고른 좌석은 5분 동안 잡아 둡니다.
  3. 할인 종류(어른·경로 등)를 확인하고 장바구니 담고 음료 고르기 또는 바로 결제 →.
  4. 음료와 같은 장바구니로 한 번에 결제합니다. 쿠폰·포인트 할인은 음료에만 적용됩니다.

8. 회원가입

  1. 시작 화면 처음이신가요? 회원가입 → → 이름, 아이디, 비밀번호(두 번), 전화번호를 입력합니다. 전화번호는 숫자만 치면 010-0000-0000 모양이 됩니다.
  2. 알레르기가 있으면 검색해서 고릅니다.
  3. [필수] 개인정보 동의를 체크합니다. 얼굴 로그인을 쓰려면 [선택] 얼굴 정보 등록 동의도 체크합니다.
  4. 다음을 누르면 바로 My Menu로 가거나(얼굴 동의 안 함), 얼굴 등록 화면으로 갑니다.
얼굴은 사진이 아니라 숫자(특징값)만 암호화해 저장합니다. 시연 모드에서는 아무것도 저장되지 않습니다.

시작 화면 오른쪽 위 운영자 메뉴 → 시연 모드는 admin / demo로 들어갑니다.

10. 실제 모드 — 3_실제모드_실행.bat

실제 모드는 주문·회원·얼굴 정보를 이 컴퓨터의 암호화 금고(program\data 폴더)에 저장하고, 카메라로 얼굴 인증을 합니다.

  1. 처음 켜면 금고가 없어서 검은 창에 “새 관리자 비밀번호”를 묻습니다. 직접 정해서 입력하고 Enter를 누르세요(입력해도 글자가 보이지 않는 게 정상입니다). 연습용 샘플 데이터가 함께 만들어집니다.
  2. 다음부터는 첫 화면에서 관리자 아이디 admin과 그 비밀번호로 금고를 엽니다.
  3. USB 카메라를 쓰면 program\3_실제모드_실행.bat을 메모장으로 열어 KIOSK_CAMERA=0의 숫자를 카메라 번호로 바꿉니다.
꼭 지켜 주세요
  • 관리자 비밀번호는 다른 사람·메신저·인터넷에 올리지 마세요. 잊으면 금고를 열 수 없습니다.
  • 얼굴 등록은 본인 동의를 받은 사람만 합니다.
  • program\data 폴더(회원·얼굴 정보)를 다른 곳에 올리거나 보내지 마세요.

11. 문제가 생기면

이럴 때이렇게
“Python 을 찾지 못했습니다”Python을 설치할 때 “Add python.exe to PATH”를 체크했는지 확인하고 다시 설치한 뒤 1번을 다시 실행합니다.
설치 중 오류인터넷 연결을 확인하고 1번을 다시 실행합니다. 여러 번 실행해도 괜찮습니다.
키오스크가 오류로 멈춤검은 창을 캡처하고, program\logs\kiosk_error.log 파일을 팀장에게 보냅니다.
얼굴 인증이 안 됨밝은 곳에서 카메라를 정면으로, 50cm 안에서 봅니다. 마스크·선글라스는 벗습니다. 안 되면 비밀번호로 로그인.
얼굴 로그인이 잠김비밀번호로 한 번 로그인하면 풀립니다.
카메라가 안 잡힘카메라 번호(KIOSK_CAMERA)를 0, 1, 2로 바꿔 봅니다. program\tools\check_camera.py로 확인할 수 있습니다.
화면이 너무 작음/큼시작 화면 큰 글자를 쓰거나, 전체 화면으로 켜려면 명령 창에서 2_시연모드_실행.bat --fullscreen.
