1. 한눈에 보기

26플로차트 갈래별 시나리오 (2가지 화면 크기로 52번 실행)

주제는 “사용자를 기억하는 KIOSK”입니다. 현금 결제 카페 키오스크(브랜드 COFFEE & SPOON)를 Python(PySide6) 화면 프로그램으로 만들었습니다. 회원은 얼굴·비밀번호·회원 카드로 로그인하고, 키오스크는 지난 주문·좋아요·알레르기·카페인 섭취를 기억해 다음 주문을 돕습니다. 버스 터미널 안 카페를 가정해 승차권 탭도 같은 장바구니에서 결제합니다.

팀공학 한 스푼 — 김보민(팀장), 조민기, 김지성, 김휘원, 임예찬
저장소GitHub BONGMIN-AI/KIOSK-program (main)
실행Windows · Python 3 · 인터넷 없이 동작(처음 설치 때만 필요)

2. 전체 흐름 (플로차트 v4)

대기 화면 → 시작(HOME) ─┬ 회원 → ID 또는 RFID 카드 → 얼굴 인증(실패·3번 잠금 → 비밀번호 · 찾기 02-C) → My Menu
                         ├ 비회원 → 메뉴(커피 탭부터)
                         ├ 회원가입 → (얼굴 등록 선택) → My Menu
                         └ 운영자 → 메뉴·회원·이벤트·포인트 → 로그아웃
메뉴(My Menu · 인기 · 승차권 · 커피 …) → 옵션(알레르기 경고 · 카페인 알리미) → 장바구니
  → (회원) 쿠폰·포인트 → 현금(부족 안내 · 45초 경고 · 60초 반환 · 0원 결제 · 잔돈 포인트)
  → 완료(대기 번호 · 승차권 · 거스름돈 안내) → 더 주문하시겠어요?(15초) → 예: 메뉴 / 아니요: 대기 화면

6. 남은 한계와 주의할 점

  • 현금 투입은 화면 버튼으로 흉내 냅니다. 실제 지폐·동전 기기, 영수증·승차권 프린터와는 연결하지 않았습니다.
  • 승차권은 시뮬레이션입니다. 실제 버스 회사 예매 시스템과 연결되지 않습니다.
  • RFID 카드는 RC522 + 아두이노 Uno 리더로 실물 카드 인식·로그인까지 확인했습니다. 키보드처럼 입력하는 USB 리더도 그대로 됩니다.
  • 얼굴 인증은 교실 조명·카메라에서 한 번 더 시험해 기준값(KIOSK_FACE_THRESHOLD)을 맞추는 것이 좋습니다. ArcFace 모델은 비상업 연구용이라 배포 폴더에 넣지 않고 설치 때 내려받습니다.
  • 언어는 대기·시작 화면만 바뀌고, 그다음 화면은 한국어입니다.
  • 인기 탭 순위는 시연용 가상 기록에 실제 주문·좋아요를 더한 값입니다.
  • ICE·HOT 사진이 같습니다(추가 아이디어 P2).
