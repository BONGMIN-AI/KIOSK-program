꼬였으면 처음으로 / 로그아웃 → 그 단계부터 다시. 비밀번호는 모두 1234.

4. 임예찬

로그인 비회원 (아이디 없음)
보여 줄 것 예매표 출력 (이름 + 휴대폰 번호) · 비회원 주문 · 예매표 0원 · 커피와 함께 결제
1
대기 화면 누르기 → 매장에서 먹어요 → 비회원 주문
메뉴 화면 · 위쪽 ‘비회원 주문’
회원이 아니어도 바로 주문할 수 있어요.
2
승차권 탭 → 예매표 출력
예매표 출력 · 조회 (이름 + 휴대폰 번호)
3
이름 임예찬 · 휴대폰 번호 01020072007 → 조회
예매한 표 2장 · 출발까지 남은 시간
인터넷이나 앱으로 예매한 표를 이름과 휴대폰 번호로 찾아요. 예매번호로도 돼요.
4
뒤의 표를 눌러 체크를 빼고 → 장바구니에 담기
‘장바구니에 담았어요 · ○번 승차장’ · 장바구니에 예매표 0원
이미 돈을 낸 표라서 0원으로 담겨요. 결제를 마치면 출력돼요.
5
음료 고르기 → 커피에서 하나 → 장바구니 담기
장바구니에 예매표 + 음료
표를 받으면서 커피도 같이 사요.
6
장바구니 확인 → 결제하기 → 돈 넣기 → 투입 취소 · 반환
넣은 현금이 그대로 돌아옴
잘못 넣었으면 언제든 돌려받을 수 있어요.
7
다시 돈 넣기 → 결제 완료
완료 화면 · 대기 번호 · 승차권 정보
비회원은 대기 번호로 불러요.
8
아니요 · 끝내기 → 비회원 주문 → 승차권 → 예매표 출력 → 같은 이름 · 번호로 조회
방금 받은 표는 빠지고 1장만 나옴
한 번 출력한 표는 다시 출력되지 않아요.
