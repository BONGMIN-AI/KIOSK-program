발표 시연 전체 진행표 (팀장용)

팀원이 단계별로 누르는 동안 팀장이 ‘팀장 설명’을 말해요

1. 김지성2. 김휘원3. 조민기4. 임예찬
켜기: 팀장 노트북에서 시연 모드 (카메라 · 카드 리더 연결). 순서대로 이어서 해요 (앞 사람이 가입한 회원 · 등록한 얼굴이 그대로 남아 있어야 해요 · 중간에 프로그램을 끄지 않기).
꼬였으면 처음으로 / 로그아웃 → 그 단계부터 다시. 비밀번호는 모두 1234.

1. 김지성

로그인 jisung0642 · 비밀번호 1234 · 그 자리에서 얼굴 등록
보여 줄 것 다가가면 시작 · 얼굴 등록 · 얼굴 로그인 · 버스표 구매 · 미소 미션 · 잔돈 포인트 · 새 칭호
1
카메라에서 1m 밖에 서 있다가 키오스크로 천천히 다가가기카메라
가운데에 매장 / 포장 버튼 두 개가 스윽 떠오름
화면을 누르지 않아도 손님이 다가오면 키오스크가 먼저 알아보고 주문을 시작해요.
2
포장해 갈게요
시작 화면 (회원 주문 · 비회원 주문)
주문을 시작하면 먼저 매장인지 포장인지 골라요.
3
회원 주문 → 아이디 jisung0642 → 비밀번호로 로그인 → 1234 → 얼굴도 등록할게요 체크 → 로그인 →카메라
얼굴 등록 화면 (귀여운 라떼 얼굴)
얼굴은 사진이 아니라 특징값만 암호화해서 저장해요. 처음 한 번만 등록하면 돼요.
4
카메라 50cm 안에서 정면을 보고 잠시 멈추기카메라
고리가 초록으로 차고 체크 → 메뉴 화면 · ‘… 김지성 님, 오늘 두 번째 방문이에요!’
오늘 이미 왔던 것도 기억해서 인사가 달라져요.
5
로그아웃 → 예, 로그아웃 → 1m 밖으로 물러났다가 다시 다가가기 → 포장해 갈게요카메라
매장 / 포장 버튼이 다시 떠오름
6
회원 주문 → 아이디 jisung0642 → 얼굴 인증 → 정면 보기카메라
비밀번호 없이 로그인 · 메뉴 화면
이제는 얼굴만 보면 로그인돼요. 사진을 들이대는 건 막아요.
7
승차권 탭 → 승차권 구매 → 출발지 그대로 · 도착지 대전복합 · 날짜 → 검색 →
시간표 · 버스마다 ‘○석 남음’
출발지 · 도착지 · 날짜를 고르면 남은 좌석과 요금이 나와요.
8
버스 하나 → 다음 → 좌석 하나 누르기 → 다음 →
좌석이 빨갛게 · ‘5분 동안 잡아 둬요’
고른 좌석은 5분 동안 다른 사람이 못 가져가요.
9
승객 혜택에서 경로 → 장바구니 담고 음료 고르기
승차권 금액이 할인되고 장바구니에 승차권
경로 · 보훈 · 군인 · 장애인 할인을 고를 수 있어요.
10
디카페인 → 디카페인 아메리카노 → 장바구니 담기
장바구니에 버스표 + 음료
커피와 버스표를 한 장바구니에 담아 한 번에 결제해요. 이게 우리 키오스크의 핵심이에요.
11
장바구니 확인 → 미소 미션 체크 → 카메라 50cm 안에서 웃기카메라
‘카메라를 켜는 중이에요’ → 커피잔이 웃는 얼굴로 → ‘미소 미션 성공!’ −500원
웃으면 500원 할인이에요. 웃은 시간이 3초 모이면 성공이고, 계정마다 한 번이에요.
12
결제하기 → 결제로 이동 → 현금 넉넉히 (예: 10,000원 두 번) → 잔돈 … 포인트 적립 체크 → 결제 완료
완료 화면 · 포장 · 승차장 · ‘★ 새 칭호 획득! [단골손님]’
잔돈은 동전 대신 포인트로 쌓을 수 있어요. 주문이 쌓이면 새 칭호도 받아요.
13
‘더 주문하시겠어요?’ → 아니요 · 끝내기
처음 화면

2. 김휘원

로그인 withtop77 · 비밀번호로 로그인 (얼굴 없이)
보여 줄 것 비밀번호 로그인 · 인사와 칭호 · 생일 쿠폰 · 우유 알레르기 · 카페인 알리미 · 다시 담기 · 좋아요 · 저장한 노선 · 숨은 쿠폰
1
대기 화면 누르기 → 매장에서 먹어요 → 회원 주문

2
아이디 withtop77 → 비밀번호로 로그인 → 1234 → 로그인 →
팝업 ‘생일 축하해요!’ · 위쪽 ‘[얼죽아] 김휘원 님, 2일 만이에요!’
얼굴이 싫은 손님은 비밀번호로도 돼요. 생일을 기억해 축하 쿠폰을 주고, 마지막 방문일을 기억해 인사해요.
3
팝업 확인 → 위쪽 이름 [얼죽아] 김휘원 님 › 누르기
칭호 목록 · 다음 칭호까지 진행 막대
주문 습관으로 칭호가 붙어요. 아이스 아메리카노를 자주 마셔서 ‘얼죽아’예요.
4
닫고 My Menu → 최근 주문 다시 담기 ▶
‘카페인 알리미 · 그래도 담을까요?’
지난 주문을 버튼 하나로 다시 담아요. 이번 주 카페인 제한을 넘으면 한 번 물어봐요.
5
아니요 → 카페인 블록 오른쪽 위 톱니바퀴 → + 두 번 → 완료
제한이 바로 늘고 ‘○잔 남았어요’
손님이 이번 주 카페인 양을 직접 정해요. 잔 수로도 mg으로도 돼요.
6
다시 다시 담기 ▶
이번에는 바로 장바구니에 담김
7
커피 → 아메리카노 누르기
옵션 창에 ICE · L · 샷 추가가 미리 골라져 있음
자주 시키던 옵션을 기억해서 미리 골라 줘요.
8
옵션 창 닫기 → 커피 → 카페라떼 → 장바구니 담기
‘알레르기 주의 · 우유’
가입할 때 적은 알레르기를 기억해서, 든 메뉴를 담으면 알려 줘요.
9
취소 → 음료 하나의 ♡ 누르기
♥로 바뀌고 My Menu 좋아요에 들어감
좋아하는 음료를 모아 둘 수 있어요 (최대 6잔).
10
My Menu → ★ 저장한 노선 서울경부 → 대전복합
승차권 탭의 오늘 시간표가 바로 열림
자주 가는 노선은 저장해 두면 출발지 · 도착지를 안 골라도 돼요.
11
메뉴 화면 왼쪽 위 로고를 빠르게 5번
‘숨은 쿠폰을 찾았어요!’
숨겨 둔 재미 요소예요.
12
장바구니 확인 → 결제하기 → 생일 쿠폰 고르기 → 결제로 이동 → 현금 버튼으로 돈 넣기 → 결제 완료

3. 조민기

로그인 그 자리에서 회원가입 (아이디 asd1625 · 비밀번호 1234) · 얼굴 · 회원카드

3

6
아니요 · 끝내기 → 다시 매장에서 먹어요 → 회원 주문 → asd1625 → 얼굴 인증카메라
‘받으신 회원카드를 리더기에 대면 등록돼요’ · My Menu 맨 위 카드 등록

7

팝업 ‘회원카드 등록 완료!’ (이번 주문 10% · 앞으로 3% 적립)
처음 대면 카드 번호가 등록되고, 이번 주문은 10% 할인돼요.
8
음료 하나 담기 → 장바구니 확인 → 결제하기 → 결제로 이동 → 현금 버튼으로 돈 넣기 → 결제 완료

카드로 주문할 때마다 도장이 하나씩. 10개 모으면 음료 한 잔이 무료예요.
9
아니요 · 끝내기 → 처음 화면에서 카드만 리더기에 대기카드 리더기
‘조민기 님 카드 확인’ · 매장 / 포장 버튼
다음부터는 카드만 대면 아이디를 안 쳐도 돼요.
10
매장에서 먹어요 → 카메라 보기카메라

4. 임예찬

로그인 비회원 (아이디 없음)

1
대기 화면 누르기 → 매장에서 먹어요 → 비회원 주문

2
승차권 탭 → 예매표 출력
예매표 출력 · 조회 (이름 + 휴대폰 번호)
3
이름 임예찬 · 휴대폰 번호 01020072007 → 조회
예매한 표 2장 · 출발까지 남은 시간
인터넷이나 앱으로 예매한 표를 이름과 휴대폰 번호로 찾아요. 예매번호로도 돼요.
4

‘장바구니에 담았어요 · ○번 승차장’ · 장바구니에 예매표 0원
이미 돈을 낸 표라서 0원으로 담겨요. 결제를 마치면 출력돼요.
5
음료 고르기 → 커피에서 하나 → 장바구니 담기
장바구니에 예매표 + 음료
표를 받으면서 커피도 같이 사요.
6
장바구니 확인 → 결제하기 → 돈 넣기 → 투입 취소 · 반환
넣은 현금이 그대로 돌아옴
잘못 넣었으면 언제든 돌려받을 수 있어요.
7
다시 돈 넣기 → 결제 완료
완료 화면 · 대기 번호 · 승차권 정보
비회원은 대기 번호로 불러요.
8
아니요 · 끝내기 → 비회원 주문 → 승차권 → 예매표 출력 → 같은 이름 · 번호로 조회
방금 받은 표는 빠지고 1장만 나옴
