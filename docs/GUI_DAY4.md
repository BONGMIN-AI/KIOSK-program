## 카메라 · 깊이
- `face/opencv_face.py`: D435가 연결돼 있으면(`KIOSK_DEPTH=0`이면 끔) 고개 동작 대신 **깊이로 입체 얼굴 확인**(눈·입꼬리 평면 대비 코 돌출, 10장 중 7장).
  약 3초 동안 계속 평평하면 "사진·화면으로 보여요"로 멈추고 02-B 비밀번호로 안내한다. 웹캠이면 예전처럼 동작 확인.
- 저장되는 것: 얼굴 특징값(128차원)만 암호화 금고 `face_profiles`. **깊이 영상·측정값은 저장하지 않는다**(판정만 하고 버림).
- 카메라 창은 아직 별도 창(OpenCV). 키오스크 창 안에 넣는 것은 다듬기 단계.

- `python -m gui.main --demo` — 메모리 샘플(저장 안 됨), 운영자 admin / demo

## 10/24 사용자 피드백 반영
- 02: 얼굴 인증 실패 뒤 처음 화면으로 돌아가면 버튼이 다시 '얼굴 인증'(다음 손님은 '재시도'가 아님).
- 02 키보드: 키가 화면 너비에 맞게 커짐(높이 54), 빈 자리에 홍보 카드 2개(사진 찍기·스마일 할인·Quick Order가 4초마다 바뀜).
- 01: 로고 600px로 크게, 회원·비회원 카드 글자 가운데 정렬·크게(제목 36, 설명 22).
- 03 메뉴 카드: 세로로 긴 카드(높이 290, 컵 그림 128), 칸 너비에 맞춰 늘어나고 화면이 넓으면 한 줄에 카드를 더 놓는다(최소 3칸, 1920 폭에서 6칸).
- My Menu: Quick Order / ♥ 좋아요한 음료 / 카페인 리포트를 각각 카드 블록으로. 좋아요가 없으면 점선 네모 + '+' + 말풍선 "좋아하는 음료를 추가해봐요!", 누르면 커피 탭.
- 얼굴 로그인 창: 카메라 영상 대신 아이폰 Face ID 같은 얼굴 기호 + 눈금 고리(진행만큼 초록), 끝나면 초록 체크를 0.6초 보여 주고 닫힘.
  로그인은 타원에 맞추지 않아도 됨(얼굴이 하나만 보이면 됨). 회원가입 얼굴 등록(10-B)만 거울 카메라를 보여 준다.
- 테스트 123개 통과. 캡처 `docs/gui_screens/` (01_home, 03_menu_fullscreen, 03_my_menu_empty, 02_face_login_window 추가).
