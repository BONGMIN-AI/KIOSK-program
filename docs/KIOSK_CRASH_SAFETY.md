# 키오스크가 갑자기 꺼지거나 오류가 날 때 (2026-10-25)

키오스크는 어느 단계에서든 꺼질 수 있다(전원·프로그램 오류·카메라 끊김). 손님 돈과 주문 기록을 지키는 장치를 정리한다.

## 1. 단계별로 꺼지면 어떻게 되나

| 꺼진 순간 | 다시 켜면 | 손님·직원이 보는 것 |
|---|---|---|
| 00 대기 ~ 05 장바구니 | 장바구니만 사라진다 (저장 전) | 처음 화면부터 다시 주문 |
| 07 현금을 넣는 중 | 넣은 현금은 넣을 때마다 금고(`cash_session`)에 기록된다 | 다음 실행 때 위쪽 안내 띠: "지난번에 꺼질 때 손님이 넣은 현금 N원이 반환되지 않았어요. 직원이 확인해 주세요" + 감사 로그 `cash_unreturned` (09-E에서 확인) |
| 결제 완료를 누르고 저장하는 중 | 회원 카드·주문·재고·주문번호·현금 기록을 **한 묶음**(`journal`)으로 먼저 적고 나서 저장한다 | 다음 실행 때 쓰다 만 묶음을 끝까지 저장(주문이 반쯤만 저장되지 않음) + 감사 로그 `journal_recovered` |
| 얼굴 인증 중 | 사진은 원래 저장하지 않는다. 카메라는 다음 실행 때 다시 열린다 | 다시 로그인 |
| 운영자 화면 | 저장 버튼을 누른 것만 남는다 | 다시 운영자 로그인 |

파일 하나하나는 원래도 '임시 파일 → 교체 + .bak 백업'으로 저장해 반쯤 쓰인 파일이 생기지 않는다(`core/storage.py`).

## 2. 프로그램 안에서 생기는 오류

- **예상 못 한 오류**(버튼 처리 중 프로그램 실수): 프로그램을 끄지 않는다. 넣은 현금은 반환하고 처음 화면으로 돌아가
  "잠시 문제가 생겨 처음 화면으로 돌아왔어요 · 넣은 현금 N원을 반환했어요 · 계속되면 직원을 불러 주세요"를 띄운다.
  오류 내용은 `logs/kiosk_error.log`에 남는다(개인 정보는 쓰지 않음). 파이썬 자체가 멈추는 심각한 오류도 같은 파일에 남는다.
- **카메라 오류**(연결 끊김·모델 없음·장치 오류): 로그인 화면 실패 칸에 "카메라를 쓰는 중 문제가 생겼어요… 비밀번호로 로그인하거나 직원을 불러 주세요".
- **60초 무입력**: 처음 화면으로. 현금이 들어 있었다면 반환하고 "오래 입력이 없어… 넣은 현금 N원을 반환했어요" 안내 + 감사 로그 `cash_refund_timeout`.
- **현금 화면 '← 장바구니'**: 넣은 돈을 반환하고 "넣은 현금 N원을 반환했어요" 안내.
- **현금이 이미 충분한데 더 넣기**: 받지 않고 "이미 충분해요 · '결제 완료'를 눌러 주세요".
- 그림 파일(배너·로고)이 없어도 멈추지 않고 빈 칸으로 둔다.
- 입력 실수(재고 부족·쿠폰 조건·비밀번호 규칙 등)는 원래대로 각 화면의 빨간 안내 글로 보인다.

## 3. 꺼졌다 켜질 때 자동 실행 (사용자가 직접 설정)

`tools/run_kiosk.bat`가 키오스크를 전체 화면으로 실행하고, **비정상으로 꺼지면 3초 뒤 다시 실행**한다.
운영자가 `KIOSK 종료`나 `Ctrl+Shift+Q`로 끄면 다시 켜지 않는다. 다시 켜진 기록은 `logs/restarts.log`.

윈도우를 켤 때 자동으로 시작하려면 (한 번만):
1. `Win + R` → `shell:startup` 입력 → 시작프로그램 폴더가 열린다.
2. `tools/run_kiosk.bat`를 오른쪽 클릭 → **바로 가기 만들기** → 그 바로 가기를 시작프로그램 폴더로 옮긴다.
3. 시연용 메모리 데이터로 켜고 싶으면 바로 가기 속성의 대상 끝에 ` --demo`를 붙인다.

> 실제 데이터로 다시 켜지면 **금고 열기(운영자 ID·비밀번호)** 화면에서 멈춘다. 암호화 금고라 비밀번호 없이 자동으로 열 수 없고,
> 이것은 일부러 둔 보안 장치다. 직원이 비밀번호를 넣으면 위 1절의 복구 안내가 나온다.

## 4. 아직 못 막는 것

- 프로그램이 꺼지지 않고 **멈춰 버리는(응답 없음)** 경우는 자동으로 다시 켜지 않는다. 직원이 `Ctrl+Shift+Q` 또는 작업 관리자로 끈다.
- 실제 지폐·동전 기계가 없는 시연이라 '반환'은 화면 안내와 기록으로만 한다.
